# Linux X11 First, Wayland via Portals Second

Slugtale's Linux port targets X11 sessions first, validated on Linux Mint Cinnamon (the maintainer's real machine, which runs X11 by default with native tray support), even though major distros now default to Wayland. On X11 every Platform Adapter seam maps directly (XTEST-synthesized insertion via the `enigo` crate, existing `tauri-plugin-global-shortcut` hotkeys, StatusNotifier tray); on Wayland, global hotkeys and synthesized input require XDG desktop portals (GlobalShortcuts, RemoteDesktop/libei) with per-DE inconsistency and consent dialogs. Rather than shipping a silently broken Wayland experience or blocking the port on portal work, the same PRD phases Wayland in second: the X11 slice detects a Wayland session and reports it as unsupported in Dictation Readiness, and portal-based hotkeys and insertion land as follow-on issues once the X11 slice is validated end to end.
